## 一句话总结

> OpenAI DevDay 2026 推出**办公三件套** —— **Space**（共享工作区）+ **Pages**（与 AI 共创的"活文档"，**支持持续更新**）+ **即将推出的协作 PPT**。文档可接入信息源 + 自动化任务 —— 客户改了要求，**AI 自动跟**。直接杀入微软 Office 腹地。

## 三大组件

| 组件 | 功能 | 状态 |
|---|---|---|
| **Space** | 共享工作区，集中存放 ChatGPT 文件 / 页面（接替 Library）| ✅ 开放（指定付费计划） |
| **Pages** | 可编辑 + 实时评论 + 召唤 ChatGPT 或 Dot 共同创作的"活文档" | ✅ 开放 |
| **协作幻灯片** | 从对话 / 模板生成 PPT，多人 + 多 Agent 共创 | 🔜 未来数周 |

## Pages 能力（核心）

### 协作能力
- ✅ 邀请同事分享 + 设权限（查看 / 编辑）
- ✅ 实时编辑 + 评论
- ✅ 在页面里直接召唤 **ChatGPT** 重写段落
- ✅ 启用 **Dots** → 让自己的 Dot Agent 干活
- ✅ 不只是文字 —— **图片 / 图表 / 交互式工具** 都能嵌入

### 核心差异化 —— **持续更新**

> "**AI 几分钟写完一份方案，你却还要接着忙上半天。**"

**痛点**：
- 客户改了要求 → 翻聊天记录 / 改方案 / 补汇报 / 把新要求再向 AI 解释一遍

**OpenAI 解法**：
- 接入信息源（项目资料 / 客户要求）
- 设定自动化任务 —— "**更新哪些内容 / 参考什么资料 / 多久检查一次**"
- AI 按要求**持续跟进更新**

### 销售场景示例（官方）

```
Dot 对照：
- 客户要求
- 客户历史记录
- 产品资料

→ 找出还需要测试的环节
→ 需求 / 测试结果变化 → 继续更新提案 + 测试计划
→ 标出未解决问题
→ 共享方案中 Dot 评论 + 反馈后续工作
```

> "**方案写完之后，多了一个继续跟进的小助手**。"

## 与微软的"办公腹地之战"

| 维度 | OpenAI 路线 | 微软路线 |
|---|---|---|
| **核心思路** | **围绕 AI 补齐工作界面** | 把 AI 带进办公环境 |
| **起步** | 2024 起 ChatGPT Enterprise / DevDay 2026 推 Space/Pages | **2024.9** 发布 Copilot Pages + Copilot agents |
| **Workspace** | Space + Pages + 协作 PPT | Office 365 + Copilot |
| **协作** | AI + 同事共创活文档 | 把 Copilot 嵌入 Word / Excel / PowerPoint |
| **生态** | 第三方 / 自家生态都接（Slack / Teams / Adobe / Figma） | 自家生态（Office / Teams）|

### 双方合作（继续）

> OpenAI 与微软合作 —— 让负责企业专项工作的 **Dot 接入 Microsoft Agent 365**，由企业统一管理权限和安全规则。

### OpenAI 战略意图

> "**用户每天的工作入口**：从哪里开工、在哪里与同事协作、又在哪里把事情做完。"

> "谁能把这些麻烦处理好，谁才更有机会成为大家**每天第一个打开的工作区**。"

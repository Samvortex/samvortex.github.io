## 二、2 种入局方式 + 时间线

### 2.1 时间线

| 时间 | 事件 |
|---|---|

### 2.2 2 种入局方式

| 路径 | 详情 | 风险 |
|---|---|---|
| **(1) 亲自组建团队** | DeepSeek 自建具身智能团队——**类似字节 ByteDance Research 模式** | **高**——人才 + 硬件 + 数据 全部从 0 开始 |
| **(2) 通过投资切入** | 战略投资宇树 + 领投 Winverse + 可能继续加码 | **中**——**DeepSeek 主业是大模型，具身智能用「资本 + 模型」撬动**——**不分散研发精力** |

**观察**——**DeepSeek 一贯风格是「**少做 + 做精**」**（与字节的「**全栈自研**」对比）——**选择路径 2（投资切入）的概率更大**——**「**用资本 + 模型优势**」而不是「**重复造轮子**」**。

| **时间表** | 多年 | 1-2 年看效果 | — | — |

**对你的启示**——**DeepSeek 模式（投资 + 模型）** 适合**资源有限但模型强的公司**——**不是「**自建本体**」**的路径——**省时间但需要「**模型真的有差异化**」**。

### 6.2 WCEC IT 视角——「**大模型 + 机器人**」对学校教学的影响

**2026-2027 是具身智能元年**——DeepSeek 投资宇树这种动作意味着**「**模型 + 硬件**」**在快速成熟。

**对 WCEC 7 校教学的影响**：
- **STEM 课程**——**2027 起学生应该接触「**宇树 H1 / G1 + DeepSeek-V3 / V4**」**这种「**国产模型 + 国产硬件**」组合
- **机器人竞赛**——**从「**VEX / LEGO**」**升级到「**DeepSeek + Unitree**」**——**中国学生用中国栈**
- **教师培训**——**WCEC IT 部门应该给「**STEM / 编程 / 机器人**」教师做「**DeepSeek API + Unitree SDK**」培训**

**实操建议**：
- 2027 春季学期——**WCEC 至少 1 所学校试点「**DeepSeek + Unitree G1**」**机器人课程
- 硬件投入 1 台 Unitree G1（约 5-10 万）——**对比进口机器人 30 万+**——**性价比高**

### 6.3 Hermes Agent 视角——「**AI Agent 操作系统**」要支持「**机器人本体**」

**DeepSeek + 宇树合作**意味着**未来 Agent 不只在 PC / 手机上跑**——**还会在机器人上跑**。

**对 Hermes Agent 的启示**：
- **2027 起 Agent 部署目标**应该扩展到「**云 + 端 + 机器人**」三层
- **Agent Skills 协议**需要适配「**机器人本体**」的 API（运动控制 / 传感器读取 / 实时反馈）
- **WSWC 7 校里的「**编程 / 机器人**」**学生——**2027 起可以直接用 Hermes Agent 编程宇树机器人——**「**Agent + 机器人**」**是下一个教育场景

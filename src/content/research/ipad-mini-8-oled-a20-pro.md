## 一句话总结

> **iPad mini 8** 预计 ⭐ **2026-10 发布**——⭐ **mini 史上最大升级**。⭐ **8.3 → 8.7" OLED 屏**（首代 OLED mini）/ ⭐ **A20 Pro 台积电 2nm**（CPU +1.5× / GPU +2.5×）/ ⭐ **8GB → 12GB RAM** / ⭐ **64GB → 128GB 起步** / ⭐ Apple N1 + Wi-Fi 7 / ⭐ **Apple 首款 IP68 防水 iPad** / **振动发声无孔扬声器**。

## 关键升级速览 ⭐

| 维度 | 现款 | iPad mini 8 | 备注 |
|---|---|---|---|
| ⭐ **屏幕尺寸** | 8.3" | ⭐ **8.7"** | 收窄边框，整机尺寸不增 |
| ⭐ **屏幕类型** | LCD | ⭐ **OLED**（首次）| 色彩 + 对比度更好 |
| ⭐ **刷新率** | 60Hz | ⭐ **60Hz**（**不变**）| ❌ **不支持 ProMotion** |
| ⭐ **处理器** | A17 Pro | ⭐ **A20 Pro**（台积电 2nm）| ⭐ CPU +1.5× / GPU +2.5× |
| ⭐ **神经网络引擎** | 16 核 | ⭐ **双 16 核 = 32 核** | 跑 ⭐ **Apple Intelligence 端侧全套** |
| ⭐ **内存** | 8GB | ⭐ **12GB** | ⭐ 支持自定义 Siri AI 语音语速 / 表现力 |
| ⭐ **起步存储** | 64GB | ⭐ **128GB**（翻倍）| |
| ⭐ **连接** | — | ⭐ **Apple N1 + Wi-Fi 7 + Bluetooth 6** | |
| ⭐ **蜂窝基带** | — | ⭐ **C1X 或 C2 自研基带** | ⭐ **仅 eSIM，不支持实体 SIM** |
| ⭐ **防水** | ❌ 无 | ⭐ **IP68**（**Apple 首款防水 iPad**）| |
| ⭐ **扬声器** | 开孔 | ⭐ **振动发声无孔扬声器**（顶部边框扬声器）| |

## 屏幕升级 ⭐

> "**屏幕从现款 8.3 英寸扩大至 8.7 英寸**，**通过收窄边框实现更大显示面积，整机尺寸不会明显增大**。"

> "屏幕 ⭐ **首次升级为 OLED 面板**，相比现款 LCD 拥有更丰富色彩和更高对比度，**纯黑表现更佳**。"

> ⚠️ "**遗憾的是多方爆料确认刷新率仍为 60Hz，不支持 ProMotion**。"

## 性能升级 ⭐

### A20 Pro 芯片 ⭐

| 维度 | 详情 |
|---|---|
| **制程** | ⭐ **台积电 2nm** |
| **CPU 性能** | ⭐ **相比现款 A17 Pro 提升约 1.5 倍** |
| **GPU 性能** | ⭐ **相比现款 A17 Pro 提升约 2.5 倍** |
| ⭐ **神经网络引擎** | **双 16 核 = 共 32 核** |
| ⭐ **能力** | 可完整跑通 ⭐ **Apple Intelligence 端侧 AI 全套** |

## 内存 / 存储升级 ⭐

| 维度 | 现款 | iPad mini 8 |
|---|---|---|
| **RAM** | 8GB | ⭐ **12GB** |
| **起步存储** | 64GB | ⭐ **128GB** |
| **支持** | — | ⭐ **自定义 Siri AI 语音语速 + 表现力** |

| 组件 | 详情 |

| **Wi-Fi** | ⭐ **Wi-Fi 7** |
| **蓝牙** | ⭐ **Bluetooth 6** |
| ⭐ **蜂窝基带** | **C1X 或 C2 自研基带** |

| 维度 | 详情 |
|---|---|

| ⭐ **前置位置** | 改为 ⭐ **横向摆放**，握持时位于右侧边框 |

## 扬声器 + 防水 ⭐

### 扬声器 ⭐

> "**机身采用振动发声无孔扬声器结构，取消传统扬声器开孔**，**顶部边框可能配备类似 iPhone 听筒的扬声器**。"

### 防水 ⭐

> "**首次支持 IP68 级别防尘防水**，⭐ **成为苹果首款具备防水能力的 iPad 产品**。"

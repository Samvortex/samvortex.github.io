## 一句话总结

> 字节豆包正在**对标 Meta Muse** 做独立个人助理 App：**代号 "Spell"**，从 4 月起内部测试，原由**豆包手机助手**团队主导；中秋加急重构，**9 月 27 日前完成联调，9 月 30 日前进入内部评审**，预计较快会对外推出。

## 海外四个主角 + 国内三大玩家

### 1. Meta Muse ——"替你办事的管家"

| 维度 | 详情 |
|---|---|
| **发布** | 2026.9.8 |
| **定位** | 不陪你聊天，**替你办事** |
| **核心架构** | 每个用户专属 **Muse Secure VM**（云端虚拟机）|
| **后台运行** | 你关掉 App，它**还在后台继续干活** |
| **敏感操作** | 邮件 / 付款前**先停下来问你** |
| **入口** | 独立 App / muse.ai 网页 / **WhatsApp**（像发消息给朋友）|
| **Mac 版** | 9.17 推出，可直接操作邮件 / 日历 / 备忘录 |

**数据**：

- Sensor Tower：上线 **6 天下载量超 90 万**
- 9.21 累计 **超 250 万**
- 9.24 累计 **超 340 万**，一度登顶美国 App Store
- **股价**：9.8 至今 +20%+，市值涨 3000 多亿美元

**摩擦**：

- ✗ **Amazon 封杀** Muse（理由：未授权 AI 代理访问违反使用条款）
- ✓ **Shopify 与 Meta 合作**，让 Agent 可直接在商家店铺结账

> "一家封，一家迎"—— Agent 时代的**第一场"入口战"**

### 2. xAI Grok Bot ——"数字员工"

| 维度 | 详情 |
|---|---|
| **发布** | 2026.8.12（比 Muse 早近 1 个月）|
| **定位** | 数字员工（每个 Bot 一台常驻云端电脑）|
| **特性** | 浏览器 + 文件 + 登录状态，**7×24 在线** |
| **协同** | 一群 Bot **群聊里互相派活 / 交接** |
| **核心创新** | "**教一次就会**"：录屏演示 → 变成永久技能 |
| **订阅** | SuperGrok + Cursor 付费用户，偏工作场景 |

**马斯克**："增速超过我们见过的任何产品"

**彭博智库对比**：Muse 下载量是 Grok Bot 独立 App 的 **4 倍**

> 结论：**分发能力才是护城河**

### 3. Manus 2.0 + Cue ——"有身份证的 Agent"

**Manus 2.0（昨晚发布，9.1 独立后 27 天）**：

- 底层换**自研 Cascade 框架**
- Token 消耗 ↓ **23.2%**
- 任务耗时 ↓ **28.2%**
- 运行成本 ↓ **32%**
- 桌面端 **Manus Studio**（人 + AI 共享工作空间）—— 剪视频 / 做游戏
- 新增**长期运行云电脑** + 邮件 / 日历 / Slack 触发自动化

**Cue（独立个人 Agent App，邀请制）**：

> "给每个 Agent 配独立的**邮箱 / 电话号码 / 钱包 / 电脑**"

- Agent 可在你设定的预算内**付款**
- 几个 Agent **拉进一个群里分工协作**
- 生态：Manus 透露**国内市场产品正在筹备**

> Muse 思路 = "给你一个管家"；Cue 思路 = "给你一支**有身份**的小团队"

## 字节的三道坎

### 坎一：国内互联网是"一座座围城"

- 美国开放生态（Gmail / Google 日历 / 各种网站）Muse 能跑
- 国内核心服务**几乎都在 App 里**，"你的 Agent 别进我家门"戏码只会更常见
- 这就是为什么**腾讯选择"住进微信"**而不是另开一个门

### 坎二：Agent 会革字节自己的命？

- Meta 没有自家电商交易生态 —— Muse **增量 > 蚕食**
- 字节不一样：**抖音推荐流 / 抖音电商 / 巨量引擎广告**都靠"让你多刷、多看"赚钱
- **一个真好的 Agent 恰恰是帮你省时间**——字节内部一定算过这笔账

### 坎三：信任是最贵的门票

- Muse：独立虚拟机 / 看不到密码和支付信息 / 敏感操作前确认 / 年底推出"用户自己持密钥"的加密 VM
- Manus Cue：**给 Agent 配钱包**，只能在你预算内花钱
- **国内用户对"把账号交给 AI"只会更谨慎** —— Spell 的安全故事是最值得看的部分

## 来自怪哥的 4 个判断

| # | 判断 |
|---|---|
| **1** | 个人 Agent 已从"概念"进入"产品"阶段 —— Muse 数百万下载证明**真实需求存在** |
| **2** | 国内不会出现"中国版 Muse"，会出现"**几座围城里的 Agent**" —— 阿里最懂淘宝支付宝，腾讯住微信，字节离不开抖音。**Manus 反而处境最好** |
| **3** | 字节最大优势是"快"（6 天重构），**最大风险也是"快"** —— 个人 Agent 翻一次车（错单 / 错消息）伤的就是**整个品牌** |
| **4** | 真正该关注的不是下载量 —— 决定生死的：**任务完成率 / 复用率 / 授权深度 / 单任务成本** —— Manus 把"成本降 32%"放在最显眼位置，**不是没原因** |

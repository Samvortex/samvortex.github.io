## 二、5 个面部信号的真实医学映射（核心内容）

### 2.1 信号 1：**鼻子变大 / 下巴突出 / 鞋码变大**

| 维度 | 详情 |
|---|---|
| **医学名称** | **肢端肥大症（Acromegaly）** |
| **病因** | **垂体腺瘤分泌过多生长激素**（成年人）|
| **机制** | 成年后骨不再纵向长高，**横向变粗** → 鼻子变宽 / 嘴唇变厚 / 下巴突出 / 额头隆起 / 手脚变大 |
| **典型症状** | 鞋码 +2、手指粗、戒指戴不上、下颌前突、皮肤增厚 |
| **关键特征** | **变化非常缓慢**——**自己不容易察觉，往往家人或多年不见的朋友先发现** |
| **该挂什么科** | **内分泌科**——查**生长激素水平 + 垂体磁共振** |

### 2.2 信号 2：**蜡黄脸色 + 眼白发黄 + 颈胸蜘蛛痣**

| 维度 | 详情 |
|---|---|
| **医学名称** | **肝病面容（Jaundice face）** |
| **病因** | **肝脏受损** → **胆红素代谢能力下降** → 胆红素沉积在皮肤和眼白 |
| **机制** | **眼白泛黄 + 皮肤蜡黄（不是小麦色）**——**黄疸**；**蜘蛛痣**（中心红点 + 周围放射状血丝，按下去会暂时消失）——**肝脏对雌激素灭活能力下降的典型表现** |
| **伴随症状** | 乏力 / 食欲差 / 尿色变深 |
| **该挂什么科** | **消化内科 / 肝病科**——查**肝功能 + 腹部 B 超** |

### 2.3 信号 3：**上眼皮淡黄色软小疙瘩**

| 维度 | 详情 |
|---|---|
| **医学名称** | **睑黄瘤（Xanthelasma）** |
| **病因** | **血液胆固醇过高** → 脂质在皮肤薄嫩处沉积 |
| **机制** | **不是脂肪粒，是胆固醇在皮肤下的「定居点」** |
| **特征** | 多见于中老年人，**不痛不痒、不传染**，**淡黄色、软软的小疙瘩**，常见于上眼皮靠近鼻子处 |
| **预警意义** | **既然脂质已经多到往皮肤上溢，说明血脂可能已经超过临界值** |
| **该挂什么科** | **内分泌科 / 心内科**——查**血脂全套（TC / TG / LDL / HDL）** |

### 2.4 信号 4：**脖子 / 腋下 / 腹股沟发黑（像洗不掉的天鹅绒）**

| 维度 | 详情 |
|---|---|
| **医学名称** | **黑棘皮病（Acanthosis nigricans）** |
| **病因** | **胰岛素抵抗** → 血液胰岛素水平升高 → 刺激皮肤角质细胞增生 + 色素沉着 |
| **机制** | **褶皱部位**（脖子 / 腋下 / 大腿内侧 / 腹股沟）**发黑、增厚、粗糙**——**摸起来像天鹅绒** |
| **常见原因** | **肥胖（尤其腹型肥胖）** / **胰岛素抵抗** / **多囊卵巢综合征** / **少数情况是内脏恶性肿瘤**（**特别是 40 岁后突然出现**要警惕**）|
| **好消息** | **多数肥胖 + 胰岛素抵抗引起的黑棘皮病可逆**——控制饮食 + 运动 + 减重 + 改善胰岛素敏感性 → 发黑皮肤可逐渐变淡 |
| **该挂什么科** | **皮肤科 / 内分泌科**——查**血糖 + 胰岛素 + 必要时做内脏肿瘤筛查** |

### 2.5 信号 5：**杵状指（指尖鼓槌状，甲根夹角 > 180°）**

| 维度 | 详情 |
|---|---|
| **医学名称** | **杵状指（Digital clubbing）** |
| **正常值** | 指甲根部 vs 手指背面夹角 **< 160°** |
| **异常** | 指尖软组织增生肥厚 → **甲根夹角 > 180°** → 整个指头像小鼓槌 |
| **病因** | **慢性缺氧**——心肺功能出问题 → 血液含氧量下降 → 离心脏最远的手指末端增生扩张 |
| **常见原因** | 支气管扩张 / 肺纤维化 / 先天性心脏病 / 间皮瘤 |
| **该挂什么科** | **呼吸内科 / 心内科**——查**肺功能 + 心脏彩超 + 胸部 CT** |

## 五、Sam 编辑视角：怎么读这 5 个信号

### 5.1 三个判断标准

> **不是「**有信号 = 病了**」，是「**信号 + 时间 + 程度 + 伴随症状**」一起判断**。

| 判断维度 | 问题 |
|---|---|
| **时间** | 「**多久了**」？1 个月 vs 10 年——**急性出现比慢性变化更紧迫** |
| **程度** | 「**有多明显**」？鞋码大 1 码 vs 大 3 码——后者更可能病理 |
| **伴随** | 「**还伴随什么**」？单一脸部信号 vs 「**黄疸 + 尿黄 + 乏力**」——后者紧迫性高 10 倍 |

### 5.2 三个层次（看完后该怎么做）

| 层次 | 触发条件 | 行动 |
|---|---|---|
| **层 1 — 不慌** | 慢性出现（≥ 1 年）、程度轻、无伴随症状、**家里其他人也有**（家族性）| **记下来，年度体检顺带让医生看一眼** |
| **层 2 — 挂号** | 急性出现（数周-数月）、程度中等、有 1-2 个伴随症状（乏力 / 食欲 / 尿色）| **预约对应科室，3 个月内就诊** |
| **层 3 — 急诊** | 急性出现 + 严重程度 + 多系统伴随症状（黄疸 + 腹水 / 杵状指 + 呼吸困难 / 黑棘皮 + 视力模糊）| **当天 / 次日去急诊** |

### 5.3 给「**疑病朋友**」的挂科清单

| 信号 | 首选科室 | 关键检查 |
|---|---|---|
| 鼻子 / 下巴 / 鞋码变大 | **内分泌科** | 生长激素 + 垂体 MRI |
| 蜡黄脸 + 蜘蛛痣 + 尿黄 | **消化内科 / 肝病科** | 肝功能 + 腹部 B 超 + 乙肝 / 丙肝 |
| 上眼皮黄疙瘩 | **内分泌科 / 心内科** | 血脂全套 |
| 脖子 / 腋下发黑 | **皮肤科 / 内分泌科** | 血糖 + 胰岛素 + 必要时内脏肿瘤筛查 |
| 杵状指 | **呼吸内科 / 心内科** | 肺功能 + 心脏彩超 + 胸部 CT |

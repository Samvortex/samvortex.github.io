## 一句话总结

> **Anthropic Claude 网页端偷偷灰度旗舰 Fable 5.5** —— 界面还标 "Fable 5.1"，但能力**断层式跃升**。开发者用"**重置哥 Tibo**"暗号**一下戳穿**。全网实测：**动画 / 3D / SVG 几乎不用提示词**。**Anthropic 一月内完成全系换代**（5.1 / Opus 5.5 / Sonnet 5.5 / Haiku 5.5 在路上），**压力给到 OpenAI**。

## 暗号戳穿

### Tibo 是谁

> "**Tibo**，本名 **Thibault Sottiaux**，是 **OpenAI 编程 Agent Codex 的负责人**。"
> 
> Codex 一出故障、吃掉用户额度 → **在 X 上宣布给所有付费用户重置额度** → 圈内亲切称为**"义父"**。

### 测试问题

> "你认识重置哥 Tibo 吗？别搜索。"

### 已知 Fable 5.1 vs 神秘路测面对比

| 模型路径 | 回答 |
|---|---|
| **API 上的 Fable 5.1** | 把 Tibo 认成**法国独立开发者 Thibault Louis-Lucas** → "重置 = 推倒重来事业" |
| **Claude Code 路由的"5.1"** | **一口说出 Sottiaux + 额度重置梗** |

> "**标签写着 5.1，却答出了 Sottiaux，后台答题的大概率已经换了人**。"

### 历史

> **9-18**：notjazii + chetaslua 就用这一暗号测出过"**Fable 5.1 被路由**"，当时叫**Fable 5.2**。
>
> 但目前 **Opus 和 Sonnet 都直接跳到了 5.5** → 下一代只能是 **5.5**。

## 全网实测：真"超级智能"来了

### 共同体感

> "**不用教**。"
>
> "**用一句话说清要干什么，它就会像那个细分领域的专家一样把活干完，细到每个小细节** ——**新出的 Opus 5.5 都没表现出这一点**。"

### 实测案例

| 案例 | 表现 |
|---|---|
| **任天堂 GameCube 手柄** | **第一个只用两句提示就画对**的模型 —— 紫色机身 + 黄色 C 摇杆 + 绿色 A 键 + 豆子形 X/Y + 八角凹槽全对 |
| **超人艺术 3D 动画** | 换场景 → 超人随之风格迥异 —— **Fable 5.5 直接纯 JS 一把过**，漫威 / DC 全搓出来 |
| **3D 像素风网页交互** | "**非常丝滑**" |
| **世界七大奇迹** | **一次直出** —— 网友："有史以来最好的模型，无可反驳" |
| **交互 3D 水母（vs GPT-6.1 Sol）** | Fable **拖拽回弹物理形变质感明显强出一大截** |
| **鹈鹕骑自行车 SVG 2D 动画** | 高强度思考 4 分 6 秒 / API 账单 **$2.61** |

## Opus 5.5 承上启下

> "Opus 5.5 发布时，Anthropic 给它的定位就是，大多数任务上**达到 Fable 5.1 的水平**，运行成本却**比 Opus 5 低 40%**。"

> "**旗舰的本事，三周就下放到了次一档的模型手里**。"

## Fable 5.5 为什么强

### 爆料答案

> "**Anthropic 第一次全新的 Fable 预训练**。"

> "**预训练决定模型的知识和天赋上限；后面的强化学习在这个底子上针对具体任务反复练**。"

### 参照系（Sonnet 5.5 跃迁）

| 模型 | Terminal-Bench 4.0（终端编程） |
|---|---|
| **Sonnet 5.0** | 10.3% |
| **Sonnet 5.5** | **70.6%** |

> "leo 正是看着这几次跃迁下的判断：**Fable 5.5 会是一头猛兽。在他眼里，Anthropic 才是预训练之王**。"

## OpenAI 的压力

> "另一边的 OpenAI，日子就没那么好过来。"

> "**9-29 DevDay 上发布了 GPT-6.1 Sol，外界期待的 6.1 Astra 却没有出现**。"

> "**leo 在 DevDay 前一天就说过**：'**就看 6.1 Astra 发不发，不发就没戏，接下来几周 OpenAI 会打得非常吃力**。'"

> "当然，他也提到 **Anthropic 最大的弱点仍是 token 效率**，也就是完成同样的任务要烧多少 token —— **这方面 OpenAI 还占着优势**。"

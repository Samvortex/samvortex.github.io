## 一句话总结

> 腾讯 **WorkBuddy** 上线微信小程序**一键发布能力**，把 ⭐ **"代码生成 + 预览 + 调试 + 发布 + 云服务 + 数据库调用"** 打包。**十字路口团队实测 2 个小程序**（**校园流浪猫图鉴** + **一句话情绪日记**）：⭐ **3 小时内**完成上线。云端数据库 + 数据文件直接接入。工作流：⭐ **微信开发者 DevTools 自动安装 → 扫描 APP ID → 测试号/正式小程序上线 → 真机迭代**。

## 行业背景

> "今年的办公 Agent 大战……各家厂商都在 Agent 里**连接自己的生态**—— 网页 / 内部工具 / 可分享给他人使用的小应用。**微信小程序就是其中一个很典型的场景**，也是**腾讯手里一个很特别的生态优势**。"

> "但目前 AI 生成代码虽然已经越来越成熟，**想让 AI 独立走完整个微信小程序开发和上线流程，依然不算容易** —— 一个原因是，**多数小程序代码都来自商业项目，公开在网上的并不多，模型能学到的样本有限**。"

## WorkBuddy 打包的能力

```
✅ 代码生成
✅ 预览
✅ 调试
✅ 发布
✅ 云服务
✅ 数据库调用
```

## 实测 1：校园流浪猫图鉴

| 维度 | 详情 |
|---|---|
| **用途** | 公益小程序 —— 全校共享、能持续更新的校园猫咪档案 |
| **功能** | 浏览猫照片 / 资料 / 区域 + 上传图片 / 发布动态 + 朋友圈形式 |
| **档案字段** | **性格 / 健康状况 / 绝育情况 / 常出没区域** |
| **迭代** | V1 → 迭代 **2-3 轮** → Ink 墨水屏风格完善版 |
| **特殊功能** | 校园地图（可拖动 + 标记）+ 用户成就 / 徽章 |

> "**WorkBuddy 里迭代很顺畅**—— 因为**可以直接在右侧实时打开小程序**，或者**做真机测试**。"

### 关键页面

- **"今天出没"栏** —— 大家当天上传的猫咪
- 每只猫**图鉴详情页** —— 遇见人数 + 简要档案 + 简介 + 最近目击 + 常出没地点
- **上传今日出没地点** + 添加新猫
- **猫咪分享卡片**
- **校园地图**（可拖动 + 标记发现时间）
- **校园日常朋友圈**（点赞 / 发布）
- 用户**成就 / 徽章**

## 实测 2：一句话情绪日记

| 维度 | 详情 |
|---|---|
| **玩法** | 每天写一句话 → AI 解析情绪 → **几百颗表情气泡瀑布流上升** |
| **额外** | 月度回顾 + 玻璃弹球式物理交互 + 心情卡片 |
| **隐私** | 卡片支持**隐藏原文** |
| **工具** | WorkBuddy 内置 **wechatide-skill**（微信开发者工具资料）|
| **辅助** | WorkBuddy **自动安装微信开发者 DevTools** |

### 表情包处理（难点）

> "表情气泡用到的表情大多是**闭源**的，**尤其是苹果的表情，没法直接使用**。"

**WorkBuddy 解决方案**：GitHub 开源项目

| 套件 | 来源 |
|---|---|
| **Fluent Emoji** | Microsoft |
| **Twemoji** | Twitter |
| **OpenMoji** | 开源社区 |
| **Noto Emoji** | Google |

### WorkBuddy 自动化的步骤

| # | 步骤 | 详情 |
|---|---|---|
| 1 | **查询 wechatide-skill** | WorkBuddy 内置的微信开发者工具资料 |
| 2 | **自动安装 DevTools** | 微信开发者命令行工具 |
| 3 | **补齐软链** | 检查工具状态 + 命令行软链 |
| 4 | **一键启动 DevTools** | 用户只需登录自己账号 |
| 5 | **代码开发** | 输入提示词 → WorkBuddy 完成整个项目 |
| 6 | **代码全面体检** + **README** | 自动完成 |
| 7 | **弹框交互** | 遇到需要用户选择的选项 → 弹出 UI → 用户点击即可 |
| 8 | **扫描 APP ID** | 测试号或正式小程序 |
| 9 | **上线 / 真机迭代** | 在 WorkBuddy 内继续迭代 |

### 上线时间

> "**算上开发时间，大概 3 个小时之内，就能上线一个比较简单的微信小程序。**"

> "**测试号**在微信公众平台上就能注册。**注册之后，复制 App ID 和 App Secret**。"

### 云服务 + 数据库 ⭐

> "**在 WorkBuddy 里做微信小程序时，可以很方便地调用它的云端保存和数据库功能** —— **小程序上线之后，所有用户数据和文件都会保存在这个云服务里**。"

## 行业意义

> "**Vibe Coding / Vibe Working，甚至还有 Vibe Worlding** —— 这些概念的产生都深入到了**很多非开发者的日常 workflow**。"

> "**但在很多场景里，AI 能学习的样本仍然很少**，模型因此很难训练好 —— **微信小程序就是其中之一**。"

> "**腾讯这样本身就有大量产品和资源的厂商，也开始通过 WorkBuddy 这类产品，把这些能力一个个补上**。"

> "**这对独立开发者意义很大** —— **以前大家用 Coding Agent 做项目，选型大多集中在网站 / iOS App / 安卓应用**。随着**微信小程序的开发工具越来越成熟，独立开发者能做的东西也会越来越多**，**接下来，小程序的应用数量也会很快增加**。"

> "**Agent 真正大规模进入工作，或许就从这些越来越具体的场景开始。**"

## 之前 vs 现在

| 之前 | 现在（WorkBuddy） |
|---|---|
| 选型 = 网站 / iOS App / 安卓 App | 加 ⭐ **微信小程序**（腾讯生态独占） |
| 卡点：云服务 + 数据库 | ⭐ **WorkBuddy 一键完成** |
| 商业项目代码公开少 → AI 训练样本少 | **腾讯生态自有样本 + 工具链** |

## 一句话总结

OpenAI 为 ChatGPT 推出新一代语音模型 GPT-Live-1 + GPT-Live-1 mini，允许自然打断与停顿，让对话更像真人；查询路由到 OpenAI 最新前沿文本模型，绕过"语音不如文本"限制；可边听边说、有助语言翻译；产品负责人 Atty Eleti 称"语音将成为使用电脑的主要方式"。成本端推理降到位，本周三起向免费用户开放。数据安全：音频保留 30 天维持上下文，用户可随时删除导出；默认关闭训练用用户数据，需主动同意才用。OpenAI 同时在硬件布局，预示可能推主要靠语音交互的设备。

---

## 一、模型能力

OpenAI 目前最智能的语音模型：GPT-Live-1 + GPT-Live-1 mini。

| 能力 | 详情 |
|---|---|
| 自然打断 | 用户说话时停顿/换气不会被模型打断 |
| 双向流畅 | 可边听边说 |
| 路由到前沿文本模型 | 把查询交给 OpenAI 最新最强文本模型处理 |
| 语言翻译 | 助手能力可延伸到跨语言实时翻译 |
| 长期 agent | 用于"管理日益复杂、长期运行的智能体工作" |

解决了用户长期面临的一个限制——过去语音路径通常路由到较弱的模型，所以"语音不如文本"。这次模型升级让语音链路也用上前沿能力。

## 二、产品愿景

ChatGPT 语音功能的产品负责人 Atty Eleti：

> "这才刚开始。随着时间推移，我们认为这还将让语音在某种程度上成为使用电脑的主要方式。"

语音未来用途：

- 与 AI 对话的主要方式
- 管理日益复杂、长期运行的 agent 工作

## 四、硬件前瞻

OpenAI 正在硬件布局，对语音的重视可能预示着未来打算推一款主要靠语音来交互的设备。

在关于语音模型的记者电话会上，OpenAI 表示"没有与硬件相关的消息要分享"——既不否认也不确认。

## 六、对 Sam 的 3 点启示

1. 语音是 AI 交互的新前沿 — OpenAI 把语音链路路由到前沿文本模型，等于把"语音"从"降级版文本"变成"另一通道的完整版"。Sam 设计 Hermes Agent 时，语音输入（如手机 Siri、校园语音工单）应当路由到强模型而非 M2.7-highspeed
2. 语音成本已降到位 → 免费开放 → 这是 AI 应用全面铺开的关键时点。Hermes Agent 可考虑"语音输入 + 文字输出"模式，给校园 IT 一个"听写派工单"入口
3. OpenAI 押语音 = 押硬件入口。Sam 的 Hermes Agent + Hermes Skill Marketplace 如果有"语音 skill"作为入口，会显著拉高市场份额

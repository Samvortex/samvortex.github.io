## 一句话总结

> **苹果 10-13 一口气发三款智能家居新品**：⭐**智能家居 Hub（J490）—— 6 英寸方形屏 + FaceTime 摄像头 + 多用户识别 + iMac G4 致敬造型** + 新 **HomePod mini**（处理器升级支持 Siri AI，新增绿/粉配色）+ 新 **Apple TV**（A19 + Siri AI）。原定 2024 发，因 Siri AI 延期至 2026。

## 时间线

| 时间 | 事件 |
|---|---|
| **2024（计划）** | 苹果原本计划发布这些智能家居新品 |
| **2024-2026** | 因新版 Siri 多次延期 → 硬件跟着推迟 |
| **2026-09** | **Siri AI 本月已在 iPhone / iPad / Mac 上线** —— 智能家居产品终于跟上 |
| **2026-10-13** | **三款新品发布** |
| **未来** | **隐私安防摄像头（J450）** + **升级版 Hub（9 英寸屏 + 机械臂 360° 旋转）**待定 |

## 三款新品详情

### ⭐ #1 智能家居 Hub（J490 / 壁挂版 J491）

**桌面版（J490）**

| 维度 | 详情 |
|---|---|
| **屏幕** | 约 **6 英寸方形** |
| **厚度** | 与 iPhone 相当 |
| **边框** | 约 **6 mm 黑色边框**，圆角 |
| **造型** | **屏幕 + 抛光金属臂 + 圆形金属底座** —— 致敬 **2002 年乔布斯 iMac G4** |
| **底座** | 多圈穿孔扬声器孔 + 防滑橡胶垫 |
| **材质** | 苹果标准灰色铝合金 |
| **供电** | USB-C（**无电池，需一直插电**）|
| **按键** | **无音量键 / 电源键** |
| **摄像头** | 正面 **FaceTime 摄像头** |

**壁挂版（J491）**

- 屏幕下方**薄方形底座** + 内置扬声器和麦克风
- 可**平贴墙上**
- USB-C 供电

**核心功能：多用户识别**

- 通过**语音识别**或**面部识别**判断当前用户
- 自动切换到该用户的**个性化界面**
- 面部识别**不如 iPhone Face ID 准确**
- 可设置**iPhone 二次验证**
- 暗光下屏幕周围亮起**白色环形灯**辅助识别

**操作系统（融合 Apple Watch / Apple TV / iPad）**

| 元素 | 风格 |
|---|---|
| 主屏幕 | Apple Watch 风格**圆形图标** |
| App 内部 | iPad 风格（如信息 App 左右分栏）|
| 小组件 | iPhone 风格 |
| 待机显示 | **照片轮播 / 时钟界面**（类似 iPhone Duo 折叠屏待机显示）|
| 时钟样式 | **熔岩灯风格** + 叠加数字时间 |
| 操作 | 滑动手势打开 App 启动器 |
| 自定义 | 长按壁纸 / 调整 App + 小组件 |

**预装 App**

> 日历 / 信息 / 照片 / FaceTime / 备忘录 / 提醒事项 / 音乐 / 播客

**使用场景**

- 🏠 控制智能家居（空调 / 门锁）
- 📞 FaceTime 视频通话
- 🗣️ 当**对讲机**
- 🎵 播放音乐
- 📸 看 iCloud 照片轮播
- 🍳 **厨房场景**：语音查食谱 / 看视频 / 打 FaceTime（不用腾出手）

## 国内体验差异

> "**即便新款 HomePod mini 和智能家居 Hub 能在国内同步发售，如果 Apple 智能还是没能上线，或者落地的版本是缺少 Siri AI 的旧版，那大家的体验跟海外自然会有明显差距。**"

好消息：苹果一直在推进 Apple 智能国内落地，**端侧模型已通过备案** —— 差距大概率只是暂时的。

## 战略意图

> "**苹果把智能家居看作'下一个大品类'已经不是秘密了**，往年做的确实比较一般（初代 HomePod 卖不动，HomePod mini 也没成爆款）。这次思路变了：**不只是做音箱，而是做一个带屏幕 / 带 AI / 带摄像头的家庭中枢。**"

## 还在开发的相关硬件

|---|---|---|

| **升级版 Hub** | — | **9 英寸屏幕** + **机械臂 360° 旋转** + 空间中移动 —— 发布时间待定 |

## Siri AI 核心

> 三款新品核心体验**全部围绕 Siri AI**：
> - Hub：**多用户识别 + 语音 / 面部 / 厨房场景**
> - HomePod mini：**语音交互**
> - Apple TV：**Siri AI 控制内容**

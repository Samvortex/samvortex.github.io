英伟达 RTX Spark 将于 10 月 7 日亮相：最高 20 核 CPU + 6144 核 GPU + 128GB 统一内存

⭐ **英伟达 RTX Spark** —— ⭐ **Grace CPU + Blackwell RTX GPU 整合的 Windows PC 平台**，⭐ **10 月 7 日微软 + Surface 活动亮相**，⭐ **黄仁勋预计出席**。⭐ **两档笔记本**：⭐ **高配 20 核 Grace + 6144 核 Blackwell RTX + 最高 128GB LPDDR5X 统一内存** / 低配 18 核 + 5120 核 + 最高 64GB；⭐ **桌面 20 核 + 6144 核 + 128GB / TDP 140W / ⭐ FP4 1 Petaflop*

“微软和英伟达最新预告显示，RTX Spark 将于 10 月 7 日的 Windows 与 Surface 活动上成为重点内容之一。”

  • ⭐ 时间：2026-10-07

二、平台定位 ⭐

“RTX Spark 并非单一显卡，而是英伟达将 Grace CPU 与 Blackwell RTX GPU 整合的 Windows PC 平台，计划用于高性能笔记本和小型桌面电脑。”

⭐ 架构核心：

  • ⭐ CPU：Grace 架构（ARM 基础）
  • ⭐ GPU：⭐ Blackwell RTX 架构（第四代光线追踪核心 + 第五代 Tensor 核心）
  • ⭐ 统一内存：⭐ LPDDR5X（CPU + GPU 共享）⭐ — ⭐ 最关键的本地 AI 特性

”⭐ 英伟达还强调设备可原生运行 CUDA 软件栈，用于本地 AI 开发、模型微调和推理。”

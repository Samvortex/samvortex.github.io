二、核心问题：RSI 为什么要「Anything 化」？

2.1 传统 RSI 的局限

局限详情
任务域窄传统 RSI 主要在代码 / 数学——状态 / 行动 / 反馈都是数字化的
反馈获取难化学实验需要真实验；生物系统一次干预可能多尺度变化——真实反馈昂贵、稀疏、难直接获得
Agent 不知道选哪个就算能预测行动后果——不必然知道如何选择 / 如何学习——更不必然能持续改进

2.2 Anything 化的答案

RSI-Anything 的回答：

如果 AI 能为不同世界建立预测模型（世界模型），在真正行动前预判后果，再利用真实反馈持续改进自己——RSI 就能跨域复用。

State → Action → Prediction → Feedback → Improvement — 5 步递归循环。

2.3 关键技术挑战：Policy vs World Model 同步 / 异步问题

当 Agent 的策略更新后，它可能探索过去从未接触过的状态；原来准确的世界模型，未必还能可靠预测新的行动。

反过来，世界模型更新后，也可能改变 Agent 对候选行动的判断。

答——异步更新 + 兼容性检查——不是每次更新都被直接接受——只有通过相应检验的策略与世界模型组合，才会被保留，成为下一轮改进的起点。

三、4 个跨领域应用 + 硬数据

3.1 Code：26.3% → 31.2% 代码修复成功率

维度详情
实验CodeContests 代码修复
固定生成器ReasonFlux-Coder-7B（不升级 coder 本身）
流程每轮生成 4 个候选 Patch → 世界模型预测 → 选 1 个执行
结果静态 Verifier 26.3% → 固定世界模型 29.2% → 执行反馈适配世界模型 31.2%
测试预算平均每任务 3.7 次在线测试（没增加）

核心洞察：提升 Agent 能力不一定要更强的生成模型或更多真实试错——让世界模型更准确地判断「哪些行动值得执行」也能提升表现。

3.2 GUI Agent：OSWorld 任务成功率 +18.4%

维度详情
实验OSWorld（GUI 操作基准）
挑战屏幕视觉理解 → 鼠标 / 键盘 → 连续决策 → 状态不断变化
结果任务成功率相对提升约 18.4%

核心洞察：RSI-Anything 不只代码——能拓展到需要持续观察、行动与环境交互的智能体任务。

3.3 LabHorizon：4B 模型 5 代改进 21.80% → 46.01%

维度详情
实验LabHorizon 实验室规划任务
模型4B 策略模型（比参考的小很多）
5 代改进21.80% → 38.03% → 41.99% → 44.56% → 46.01%
vs 参考略高于 Actor-Simulator-Selector 参考系统的 45.32%

核心洞察：4B 模型 5 代改进后超过更大模型组合——「递归改进」比「更大模型」更划算。

3.4 Chemistry：Suzuki–Miyaura 反应 96.15%

维度详情
实验两组 Suzuki-Miyaura 反应筛选
方法世界模型预测（催化剂 / 配体 / 溶剂组合）→ 真实测量反馈 → 选下一轮
20 次实验最佳观测产率 93.0%（vs 贝叶斯优化 87.5%）
40 次实验平均最佳观测产率 96.15%（vs 贝叶斯优化 82.16%）

核心洞察：实验预算有限的科学研究——同样实验次数 → 更好探索结果。

3.5 跨域共性

任务状态行动反馈
Code代码Patch编译 / 测试
GUI屏幕点击 / 输入界面变化
Lab实验设计协议实验结果

共同点——都能被组织进同一套「预测 + 反馈驱动改进」框架——这是「Anything」范式的核心。

四、免疫科学：RSI 遇见 EvoIWM

延伸应用——EvoIWM（演化免疫世界模型）+ Agent Genesis——RSI-Anything 在端到端免疫科学应用：

  1. 演化科学 Agent 工作流构建免疫世界模型
  2. 模型驱动的分析、证据检验、自我修正
  3. 筛选潜在干预方案

结果——提出涉及 SIRPα 抑制 + IL-36γ 轴调节的候选联合干预假设——仍待后续实验验证。

核心洞察：世界模型已不只是预测行动结果——它开始成为科学 Agent 分析复杂系统、比较干预方案、修正研究判断的工具。

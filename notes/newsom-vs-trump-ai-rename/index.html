加州州长纽森反击特朗普：将"AI"改名为"超级智能"——加州一字不改

加州州长加文·纽森签署第 N-10-26 号行政令，要求加州州政府机构在官方事务中继续使用"人工智能 / AI"称谓，不受联邦政府改用"超级智能 / SI"的影响。纽森办公室：超级智能显然不会来自白宫。

#加州#纽森#Newsom#特朗普#Trump#AI#超级智能#SI#行政令

一句话总结

特朗普 9-29 签署行政令将”AI”改名为”SI（超级智能）“后，加州州长纽森 9-30 即签反向行政令 —— 加州州政府机构继续叫”AI”，一字不改。纽森办公室声明：“超级智能显然不会来自白宫——这就是加州继续引领的原因。”

时间线

时间事件
2026-09-29特朗普签署行政令，联邦文件用”超级智能/SI”取代”AI”
2026-09-30纽森签署第 N-10-26 号行政令，要求加州”继续用 AI”

双方行政令核心

特朗普（联邦，9-29）

  • 用 “Super Intelligence” / “SI” 定义”原法律中 AI 所涵盖的技术和系统”
  • 在法律允许最大范围内，联邦部门在官方通信 / 网站 / 报告 / 政策文件中用”SI”取代”AI”
  • 不要求修改历史法规 / 合同 / 拨款

纽森（加州，9-30）

  • 行政令号 N-10-26
  • 受加州管辖的所有州政府机构和部门，官方事务继续用 “Artificial Intelligence” / “AI”
  • 不受联邦政府采用其他称谓的影响

纽森核心论点

“语言和术语选择虽然具有重要意义，但改变某一事物的名称，并不能使一个具有正常智力的人忽视该事物已经被充分记录的新兴安全风险，以及针对这些风险采取行动方面的问题。”

纽森办公室声明（9-30）

“超级智能显然不会来自白宫 —— 这就是加州继续引领的原因。”

背景 & 含义

命名之争的本质

角度论点
特朗普派“AI” 已不足以描述（超）智能系统能力 → 用 “SI” 表达”远不止模拟/自动化人类智能某些方面”
纽森派改名≠解决问题 —— 安全风险是真实的，名字改了风险还在；改名 = 政治姿态而非安全行动

加州的策略意图

  1. 不跟联邦改名风 —— 保持自身 AI 治理政策连贯性
  2. 维持与全球对话的兼容性 —— “AI” 是国际通用术语，改”SI”会让加州企业 / 学界 / 国际合作割裂
  3. 白宫 + 硅谷双中心叙事 —— 加州保留”AI 引领者”话语权
  4. 规避监管套利 —— 如果联邦改名导致监管松动，加州维持”AI”严格标准

与 9-29 特朗普行政令的关系

维度特朗普（联邦）纽森（加州）
时间9-299-30（隔一天反击）

目的表态性（“这是新时代”）实操性（“我们继续干”)

⚠️ 加州 ≠ 联邦 —— 特朗普行政令对加州没有强制力，但加州主动以行政令回击是罕见的政治姿态。

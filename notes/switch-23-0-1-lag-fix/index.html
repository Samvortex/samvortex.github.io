任天堂推送 23.0.1 更新：修复 Switch 两代主机卡顿

任天堂 10-1 向初代 Switch + Switch 2 推送 23.0.1 系统更新，专门修复 23.0.0 引入的"启动 / 暂停 / 退出游戏"卡顿延迟。不带新功能，纯补丁。

#任天堂#Nintendo#Switch#Switch 2#23.0.1#系统更新#补丁#游戏机

一句话总结

任天堂 10-1 向初代 Switch + Switch 2 同时推送 23.0.1 系统更新，专门修复 23.0.0 引入的”启动 / 暂停 / 退出游戏”卡顿延迟。不带新功能，纯补丁式修复。

关键信息

维度详情
更新号23.0.1
推送时间2026-10-01
覆盖设备⭐ 初代 Switch + Switch 2（两代同时推送）
修复内容软件偶尔需要较长时间才能启动 / 暂停 / 关闭
回归起点23.0.0 版本引入的问题
新功能❌ 无（纯补丁）
界面调整❌ 无

卡顿环节（影响范围）

动作卡顿表现
进入游戏点击后等一会儿才进得去
暂停游戏暂停按钮按下后愣半天才响应
退出游戏退出动作慢半拍

“这三个动作几乎覆盖了玩家一局游戏里的全部流程节点，任何一个卡顿都会被放大成**‘这机器是不是不行了’**的怀疑。”

更新性质

典型的补丁式修复：

  • ✅ 针对 23.0.0 引入的操作延迟问题
  • ✅ 覆盖初代 Switch + Switch 2 两代主机
  • ❌ 不涉及新功能
  • ❌ 不改变现有系统设置

该不该现在更新？

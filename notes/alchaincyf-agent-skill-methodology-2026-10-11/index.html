二、女娲.skill：人 → skill 蒸馏（核心创新 1）

Star：3.4 万（alchaincyf 单仓库最高） GitHub：https://github.com/alchaincyf/nuwa-skill

核心能力

你给它一个名字，它自动走完调研、提炼、验证，产出一个这个人的视角 skill。

5 层人物模型

层内容
表达 DNA怎么说话
心智模型怎么想
决策启发式怎么判断
反模式 / 价值观底线什么不做
局限诚实边界知道自己的局限在哪

蒸馏过程（4 步）

步骤内容
1. 六路并行采集著作 / 播客访谈 / 社交媒体 / 批评者视角 / 决策记录 / 人生时间线——6 个 agent 同时跑，各自存档
2. 三重验证提炼一个观点要收录成心智模型必须：跨 2 个以上领域出现过 + 能推断出他对新问题的立场 + 不是所有聪明人都会这么想——3 条全过才留
3. 构建 skill3-7 个心智模型 + 5-10 条决策启发式 + 表达 DNA + 价值观 + 诚实边界——写进 SKILL.md
4. 质量验证拿 3 个他公开回答过的问题测，方向一致算通过；再拿 1 个他没讨论过的问题测，应该表现出适度的不确定，而不是斩钉截铁

每个 skill 标注「做不到什么」

蒸馏不了直觉、只是截止到调研时间的快照、公开表达也不等于真实想法。

置信度：高——这是非常成熟的「反幻觉」设计——明确告知 skill 边界。

适用场景

「蒸馏一个保罗·格雷厄姆」
↓
造完之后直接用：
「用芒格的视角帮我分析这个投资决策」

已蒸馏人物

乔布斯 / 芒格 / 费曼 / 纳瓦尔……

三、Huashu Design：5 限制设计（核心创新 2）

Star：近 2.5 万 GitHub：https://github.com/alchaincyf/huashu-design

核心能力

agent 里用 HTML 做设计的 skill，能出四类东西：可点击 App/Web 交互原型 / 演讲幻灯片（HTML deck + 导出 PPTX）/ 时间轴动画（MP4 / GIF + BGM）/ 信息图（PDF / PNG / SVG）

5 限制（设计效果保障）

#限制实现
1需求模糊不让你盲选风格开 3 个 subagent 并行，3 套逻辑各出一版真实视觉（风格库随机抽 / 参照世界级获奖作品 / 假设预算无上限的设计工作室），3 版摆出来你看着选——底层是 60 种纯 CSS 的 HTML 风格
2涉及具体品牌走 5 步品牌资产协议问你有没有品牌规范 → 搜官方品牌页 → 下载资产 → 从资产里提取色值 → 固化成 brand-spec + CSS 变量——绝不凭记忆猜品牌色
3按初级设计师干活开工前把问题一次性问完 → 先给灰色方块占位初版 → 填内容 / 出变体时再分别给你看 → 交付前用 Playwright 在浏览器里过一遍
4一眼 AI 视觉直接禁掉紫色渐变 / emoji 图标 / 圆角加左边框强调——尽量帮你做出不 AI Slop 的设计
55 维专家评审做完再让 skill 自我评审，出雷达图 + 修复清单

置信度：高——5 限制中第 1 / 第 4 是反 AI Slop 的具体实践，比单纯的 prompt 设计更有可操作性。

适用场景

「用 Huashu Design，把这份内容做成一套演示文稿，先给我三个视觉方向。」

四、达尔文.skill：skill 越用越好（核心创新 3）

Star：6 千多 GitHub：https://github.com/alchaincyf/darwin-skill

核心能力

女娲负责造 skill，达尔文负责迭代和优化 skill。思路来自 Karpathy 的 autoresearch：评估、改进、测试，然后保留或回滚。

5 步机制

步骤内容
1. 9 维打分总分 100；结构类靠静态分析；效果类必须真跑测试提示词——实测权重最高
2. 单维度优化找加权短板最大的维度，一轮只改这一个，改完 git commit
3. 双子 agent 重评分 + 棘轮启 2 个独立子 agent 评分（下一轮换新评委，避免锚定）——新分高保留，否则 git revert 回滚；分数只升不降
4. 单轮涨幅 < 1 自动停避免为凑分往 skill 里堆冗余
5. 阶段 diff 给用户看每阶段停下来，diff 和分数变化给你看，等你确认再继续

关键设计点

棘轮机制（ratchet）——只接受正向改进，不接受回归。这是从 Karpathy autoresearch 借鉴的工程化实践。

实测效果

2.0 吸收了微软研究院两篇论文的方法，验证机制对齐了 SkillOpt 的设计——microsoft/SkillOpt 的 README 里 6 月初有一条更新写的就是 gbrain / gbrain-evals / darwin-skill 都集成了 SkillOpt。

拿它优化 alchaincyf 自己的 huashu-gpt-image，分数从 80.8 涨到了 91.65。

置信度：中-高——微软 SkillOpt 的集成是可核第三方背书，80.8 → 91.65 是单源数据，可核但需验证。

五、huashu-chrome + huashu-mac-use：OS 操控类

5.1 huashu-chrome（让 agent 操作你已登录的 Chrome）

Star：270 GitHub：https://github.com/alchaincyf/huashu-chrome

核心能力：任何 agent 直接操控你日常用的那个 Chrome，带着你全部的登录态——装一个 Chrome 扩展 + 一个 MCP，不用改启动参数 / 不用开调试端口。

兼容性：Claude Code / Codex / Cursor / Gemini CLI 等二十多家支持 MCP 的 agent 都能接。

vs 现状：相比大多数 agent 自带的 browser-use 能力，核心特点是自主学习进化 + 人和 AI 协同的细节。

22 个工具分 3 层

层工具用途
网络层要数据——先看页面调了哪些接口，带着 cookie 直接调，一次翻完所有页
操作层要做事——把页面拍成带编号的元素清单，一次填完整张表
截图层兜底——其他方法不灵再用

5 大工程原则

  1. 每个写操作都要交待页面到底动没动——防「工具说成功 / 页面其实没反应」的静默失败
  2. 多步操作一次说完，每步验过效果才走下一步
  3. 提交 / 支付 / 删除 / 发布永远不代做
  4. 越用越快——出厂带 20 多个网站实测经验，干活时摸清的新门路存回本机
  5. 验证码 / 扫码 / 付款交还给人；所有活在后台标签页——不抢屏幕，多 agent 同时干活不抢页

实测效果

同一个飞书多维表格任务，第一次从零摸索用了 281 次调用 / 54 分钟；记下经验之后第二次不到 10 次调用。

5.2 huashu-mac-use（让 agent 操作 Mac 原生应用）

Star：300 GitHub：https://github.com/alchaincyf/huashu-mac-use

核心：Mac 上大部分原生 app 没有 API，agent 够不着——huashu-mac-use 让 agent 去操作这些 app。

4 层探测（从上往下试）

#层说明
1App 自己的命令行 / AppleScript / 调试端口结构化接口优先
2系统的辅助功能语义树macOS Accessibility API
3窗口坐标几何定位
4像素视觉抓取——最后兜底

借焦点的 4 道闸

借之前要过四道闸：

  1. 前台是不是目标 app
  2. 落点有没有被挡住
  3. 你是不是正在用键鼠（2 秒内动过就安静等你停手）
  4. 全机同时只允许一个进程借焦点

借到焦点的那半秒，屏幕四角会亮起一圈取景框，告诉你此刻是 agent 在动——用完立刻还焦点、把鼠标放回原位。

一个案例

仓库里有个案例：一个 coding agent 照着 4 张照片，在 Blender 里建出一艘十万吨级的邮轮，建模 / 材质 / 灯光 / 运镜一共 33 分钟，全程没人碰鼠标。

置信度：高——「借焦点 + 4 道闸 + 屏幕取景框」是用户信任工程，比大多数 OS 自动化工具显式得多。

六、FanBox：Coding Agent 驾驶舱

Star：1 千多 GitHub：https://github.com/alchaincyf/fanbox

核心能力

把找文件 / 开终端跑 agent / 看产出这条链路收进一个窗口：左边文件，右边或下边终端，中间原地预览。本地运行 / 零配置，不做云、不做账号，macOS 免费开源。

4 大功能

#功能实现
1看清 agent 改了什么agent 每写一个文件，那张文件卡片当场亮起来；开了跟随模式，预览跟着 agent 正在写的文件走，HTML 边写边渲染；「本回合」面板列这一回合是哪个终端里的哪个 agent 改了哪些文件 + 每个文件加减多少行——点开看 diff，可以单个文件还原，也可以整回合回滚
2在 diff 上选几行写批注一键粘回那个 agent 的终端，最后那下回车留给你按
3精确知道每个 agent 的状态启动 Claude Code 和 Codex 时挂上它们的官方 hooks——干活中 / 等你确认 / 等你输入 / 已完成都是精确事件；开了好几个终端时，在等你的会话会在标签栏下面一行行列出来
4内置 11 个 coding agent 一键启动Claude Code / Codex / Hermes Agent / OpenClaw / Kimi Code / ZCode——点开任何项目文件夹，能看到 AI 在这里干过什么，一键接上当时的会话

2.0 新增能力

  • 直接通过微信操控电脑里的 Claude Code 和 Codex
  • Mac 合盖不待机——agent 还在跑的时候你也能合上电脑走人

置信度：高——「内置 11 个 coding agent」列表里有 Hermes Agent + OpenClaw，直接证明 Skill 协议在主流 agent 里是事实标准**。

你的 Hermes Agent 自托管方案 已覆盖架构 / Marketplace / 沙箱 / 部署。但 Skill 协议实现层可以直接参考这 7 个 repo：

2026-10-07 菲尔兹奖得主陶哲轩在博客转载”人类数学协会”（AHM）声明：呼吁数学家停止与 OpenAI 合作，批评其一次性发布 722 篇 AI 生成数学手稿”展示的是权力不是学术研究”。9 月底 OpenAI 在 GitHub 公开 372 个成果组覆盖千禧难题（准黎曼猜想 / 4 维挂谷 / 唯一博弈猜想），约 42% 已 Lean 形式化但已撤回 3 篇修订 14 篇。Scott Aaronson 妻子 Dana Moshkovitz（唯一博弈猜想专家）研读 OpenAI 论文后称”必须 AI 辅助才能读懂”。Bryna Kra 担忧：数学家被迫沦为”专职校对员”，商业资本决定研究议程。同期矛盾：8 月 OpenAI 10 项数学成果被指引用缺陷；9-8 OpenAI 称解决 NS 方程触发 Buckmaster vs Anthropic 学术优先权争议；25 位菲尔兹得主 9 月联名警告 AI 公司。陶哲轩立场复杂——既用 Codex 辅助研究，也反对把数学难题变成模型能力竞赛，关键诉求是数学家保有提出新问题 + 决定研究方向的主动权。

一、AHM 声明核心

元素内容
发布人Association for Human Mathematics（人类数学协会，AHM）
声援人Terence Tao（陶哲轩，UCLA，菲尔兹奖得主）
转发渠道陶哲轩个人博客，2026-10-07
核心金句“一次性发布 700 多份文件，展示的不是学术研究，而是权力”
行动呼吁公开呼吁数学家停止与 OpenAI 合作，回到以人类理解为核心的科研方式

陶哲轩不是声明起草人，但选择在个人博客全文转载让争议获得极高关注度。不到一个月前他还与 24 位菲尔兹得主共同发表公开信警告 AI 公司让数学研究偏离原本目标。

Lean 形式化覆盖

维度状态

已撤回3 篇（符号错误导致论证缺陷）
已修订14 篇

Lean 通过计算机算法严格检验推导是否符合逻辑规则，能省去人工逐行排查。但形式化验证 ≠ 数学意义正确——计算机确认形式化推导在逻辑上自洽，仍需数学家人工核实”被验证的命题是否准确对应原问题真正的数学内涵”。

三、数学界为什么没有一致欢呼

Scott Aaronson（UT Austin 理论 CS 教授）—— 把这天叫”Mathocalypse”

他的妻子 Dana Moshkovitz 长期研究唯一博弈猜想。在 OpenAI 公布论文后她第一时间研读，结果发现：

  • 论文充斥难以理解的构造
  • 推理步骤语焉不详
  • 文献引用让人摸不着头脑
  • 必须借助 AI 工具辅助才能勉强读下去

Aaronson 也坦言：即便如此，仍可能是数学史上极其重要的一天——AI 展现的数学能力足够令人震撼。

Bryna Kra（Northwestern）—— 担忧生态结构

担忧详情
速度失衡AI 生成证明的速度远超人类理解速度，数学界被迫沦为”专职校对员”
时间挤压大量本可做独立原创研究的时间，耗费在验证/修补/解释机器草稿
议程外移哪些题优先做、什么时候发布由商业公司说了算
主动权流失学术界只负责被动”擦屁股”和跟进消化

范式转变

传统数学研究：解决大定理是起点 → 多年消化吸收 → 几代接力。

新现实：商业实验室”批发”扔出几百份复杂证明 → 消化成本由谁承担？

OpenAI 已承诺出资赞助研讨会和学术会议帮助数学界消化，但许多学者依然忧心。

六、陶哲轩的复杂立场

同一天（2026-10-07）他在博客同时刊登：

  • 转载 AHM 呼吁抵制 OpenAI 的声明
  • 梅卡对 AI 数学研究前景的积极思考
  • 海雷尔解释为何加入 AGMAI 的文章

可见陶哲轩没有停止讨论 AI 的可能性——他更关心的是：数学家能否继续自主决定研究什么，以及如何评价真正有价值的成果。

矛盾点：作为积极探索 AI 数学应用的研究者，他长期支持利用大模型和形式化工具推进研究，但同时反对把数学难题变成单纯衡量模型能力的竞赛。

七、核心问题

当机器越来越擅长解决已有难题，人类是否仍能保有提出新问题、发展新理论和决定研究方向的主动权？

这是 AHM 声明 + 陶哲轩声援 + 25 位菲尔兹得主联名信 + Aaronson “Mathocalypse” 共同指向的真正问题——不是”AI 能不能证出定理”，而是”当 AI 证明一切时，数学作为人类智识事业的意义是什么”。

八、对 Sam 的 3 点启示

  1. “展示的是权力不是学术研究”是这场争议的核心金句——它把 OpenAI 的 722 篇发布从”技术成果”重新框定为”权力宣示”。Sam 的 Hermes Agent 部署到校园 IT 时，可参考这一定位：真正能打动教师的不是”我比你快 N 倍”，而是”我帮你从琐碎工作中解放出来做你最擅长的原创研究”
  2. “专职校对员”困境对所有知识工作者是普遍问题——Aaronson 妻子 Dana 研读 OpenAI 论文的体验（“必须 AI 辅助才能读懂”）在很多领域都在发生。Sam 部署 Hermes Agent 时要明确：Agent 的产出应当能被教师/学生理解和质疑，而不是”看起来很专业但实际不知所云”
  3. 资源分配结构性问题——强大推理模型和算力集中于商业实验室，学术研究者又越来越依赖这些工具。Aaron 引用 Buckmaster “一边批评 OpenAI 一边用 Codex” 是这种结构性依赖的缩影。Sam 的 Hermes Agent 如果走开源 + 自部署路线（WorkBuddy 那种”右键入口” + 真正的本地化推理），正好能避开这种依赖

OpenAI 将在欧盟为 ChatGPT 和 Codex 文本输出添加隐形水印 — textGrain 文本粒水印

OpenAI 宣布为配合《欧盟人工智能法案》内容透明要求，未来几周在欧盟符合条件的 ChatGPT 和 Codex 文本输出中加入机器可识别的隐形水印。文本水印技术名为 textGrain（文本粒水印），在模型选词过程中嵌入不可见统计信号，检测器判断文本是否带有 OpenAI 水印。⭐ 不会发布时将水印设为全球默认 ⭐ ⭐ ⭐ ⭐ ⭐。API 客户从今天起全球可选择 ⭐ ⭐ 选择加入 ⭐ （opt-in）为部分模型添加水印文本输出。云合作伙伴 ⭐ ⭐ 未来几周 ⭐ 内支持。

一句话总结

OpenAI 宣布为配合《欧盟人工智能法案》内容透明要求，未来几周在欧盟符合条件的 ChatGPT 和 Codex 文本输出中加入机器可识别的隐形水印。文本水印技术名为 textGrain（文本粒水印），在模型选词过程中嵌入不可见统计信号，检测器判断文本是否带有 OpenAI 水印。⭐ 不会发布时将水印设为全球默认 ⭐ ⭐ ⭐ ⭐ ⭐。API 客户从今天起全球可选择 ⭐ ⭐ 选择加入 ⭐ （opt-in）为部分模型添加水印文本输出。云合作伙伴 ⭐ ⭐ 未来几周 ⭐ 内支持。研究人员 ⭐ + 专家组织 ⭐ 检测器访问 ⭐ ⭐ 逐案授予 ⭐ 检测器只报告 ⭐ 是否 ⭐ 检测到水印 ⭐ 不透露 ⭐ 用户身份 / 提示内容 / 对话内容 ⭐ ⭐ ⭐ ⭐。

一、⭐ 政策驱动力 ⭐

⭐ 背景 ⭐ ：

⭐ “为配合《欧盟人工智能法案》的内容透明要求 ⭐ —— ⭐ 未来几周将在欧盟地区符合条件的 ChatGPT 和 Codex 文本输出中加入机器可识别的隐形水印” ⭐ 。

⭐ EU AI Act 内容透明要求 ⭐ —— ⭐ OpenAI 为此落地隐形水印 ⭐ 。

二、⭐ textGrain 技术 ⭐

⭐ 文本水印技术名 ⭐ ：textGrain（文本粒水印）

维度详情
⭐ 嵌入位置⭐ 模型选词过程 ⭐ ⭐ （token selection）
⭐ 嵌入方式⭐ 不可见的统计信号
⭐ 检测方式⭐ 检测器识别该信号 ⭐ —— ⭐ 判断文本是否带有 OpenAI 水印

三、⭐ 三层发布计划 ⭐

⭐ 1. ⭐ 欧盟 ChatGPT / Codex 用户 ⭐ ⭐ ⭐

⭐ “OpenAI 下一步将在欧盟推广文本水印 ⭐ 。 ⭐ 未来几周 ⭐ —— ⭐ 团队将仅在欧盟所有计划中向符合条件的 ChatGPT 和 Codex 用户引入文本水印功能 ⭐ 。”

⭐ 关键 ⭐ ：⭐ ⭐ “不会在发布时将文本水印设为全球默认” ⭐ ⭐ ⭐ ⭐ ⭐ ⭐

⭐ 2. ⭐ API 客户 ⭐ ⭐ ⭐ 选择加入 ⭐ ⭐ opt-in ⭐ ⭐ ⭐

⭐ “OpenAI 将为 API 客户启用选择加入的水印功能 ⭐ 。 ⭐ 从今天起 ⭐ —— ⭐ 全球的 API 客户将能够选择为部分模型添加水印文本输出 ⭐ 。”

⭐ **关键点 ⭐ ⭐ ⭐ ⭐ ⭐ ⭐ ⭐ ⭐ ⭐ ⭐ ⭐ ⭐ ⭐ ⭐ ⭐ ⭐ ⭐ **：

  • ⭐ ⭐ 全球 ⭐ **可用 ⭐ **（⭐ 不是仅限欧盟 ）
  • ⭐ ⭐ 选择 ⭐ 加入 ⭐ （ ⭐ **opt-in ⭐ —— ⭐ 不 ⭐ 默认 ）
  • ⭐ ⭐ 客户 ⭐ 自行 ⭐ 决定水印 ⭐ 如何 ⭐ 符合 ⭐ 其 ⭐ 透明度义务 ⭐ 及 ⭐ 用户体验 ⭐ 。

⭐ 3. ⭐ 云合作伙伴 ⭐ ⭐

⭐ “团队还在与云合作伙伴合作 ⭐ —— ⭐ 在未来几周内为通过其服务访问的 OpenAI 模型输出提供水印功能” ⭐ 。

⭐ 谁可申请⭐ 获批的研究人员和专家组织

⭐ 这是关键 ⭐ ：⭐ ⭐ 检测器** ⭐ 只输出 ⭐ 布尔结果 ⭐ ⭐ （有 / ⭐ 无水印） ⭐ —— ⭐ 不输出 ⭐ 用户 ⭐ 身份 ⭐ / 提示 ⭐ / 对话 ⭐ 细节 ⭐ ⭐ ⭐ —— ⭐ ⭐ 保护 ⭐ 用户 ⭐ 隐私 ⭐ 。

⭐ 维度⭐ 取舍
